# Risk Analysis and Threat Modeling

This repository contains a threat model and a risk analysis for a small business system that manages customers, orders, and invoices.

The project was created using OWASP Threat Dragon and Microsoft Excel as part of an information security course.

## Tools

- OWASP Threat Dragon
- Microsoft Excel
